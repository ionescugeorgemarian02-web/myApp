# Prioritizare și decizie

## Scor de prioritate (transparent, relativ)

| Factor | Scală | Întrebare |
| --- | --- | --- |
| Valoare (V) | 1–5 | Cât de mult îmbunătățește o decizie din schimb (siguranță 5, calitate 4, livrare 3…)? |
| Frecvență (F) | 1–5 | De câte ori pe schimb este folosită? |
| Efort de dezvoltare (D) | 1–5 | Câte module și ce risc de regresie implică? |
| Efort de introducere (I) | 1–5 | Câte apăsări și câte minute pe schimb cere? |
| Risc (R) | veto | Confidențialitate, pretenție normativă, pierdere de date |

Scor = (V × F) / (D + I). Un risc neacceptat blochează funcția indiferent de scor. Scorul compară opțiunile între ele, nu are sens absolut.
