# Glosar Lean

**C** = confirmat pe lean.org (25.11.2026). **U** = practică uzuală, neverificată textual în sesiune.

| Termen | Definiție scurtă | Tip | Statut |
| --- | --- | --- | --- |
| Takt time | Timp disponibil / cerere. Ritmul cerut de client | Concept / calcul | C |
| Cycle time | Timp măsurat pentru o piesă sau un proces | Măsură | C |
| Just-in-time | Ce trebuie, când trebuie, cât trebuie | Pilon TPS | C |
| Jidoka | Calitate construită în proces, separarea omului de mașină. Oprire la anomalie | Pilon TPS | C |
| Heijunka | Nivelarea tipului și cantității pe o perioadă fixă | Metodă | C |
| Kanban | Semnal care autorizează producția sau transferul într-un sistem pull | Instrument / sistem | C |
| Pull | Producția este declanșată de consumul din aval | Principiu / sistem | U |
| Flow | Piesele avansează fără opriri sau loturi între procese | Principiu | U |
| Standard Work | Trei elemente: takt, secvența de lucru, stocul standard în proces | Metodă | C |
| TPM | „Total” în trei sensuri: toți angajații, toate pierderile echipamentului, ciclul de viață | Metodă | C |
| Andon | Instrument vizual care arată starea și semnalează anomalia | Instrument | C |
| PDCA | Plan–Do–Check–Act, ciclu bazat pe metoda științifică (Deming) | Metodă | C |
| Gemba / Gemba walk | „Locul real”. Observare directă înainte de acțiune | Practică | C |
| VSM | Harta fluxului de material și informație de la comandă la livrare | Instrument | C |
| Poka-Yoke | Prevenirea erorilor. Tipuri de funcție: Shutdown, Warning | Instrument | C |
| Muda / Mura / Muri | Risipă / neuniformitate / suprasolicitare („Three Ms”) | Concept | C |
| Kaizen | Îmbunătățire continuă, prin pași mici, de către cei care fac munca | Principiu / practică | U |
| SMED | Reducerea timpului de schimbare: intern → extern | Metodă | U (pagina LEI 404) |
| 5S | Sortare, Ordine, Curățenie, Standardizare, Disciplină | Instrument | U |
| 6S | 5S + Safety, variantă de companie | Instrument | U, convenție locală |
| Zero defecte | Obiectiv de calitate, sprijinit de Jidoka și Poka-Yoke | Principiu | U |
