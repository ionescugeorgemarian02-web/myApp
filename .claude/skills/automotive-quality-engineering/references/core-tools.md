# Terminologie de calitate (fără reproducerea standardelor)

Manualele AIAG / VDA și standardele IATF / ISO sunt documente contra cost. Aici apar doar sensul termenilor și implicațiile pentru aplicație.

| Termen | Sens | Implicație pentru myApp |
| --- | --- | --- |
| IATF 16949 | Standard de sistem de management al calității pentru automotive. A înlocuit ISO/TS 16949:2009 (confirmat). Este aliniat cu ISO 9001 | Doar referință. Fără pretenții de conformitate |
| ISO 9001 | Standard general de management al calității | Idem |
| APQP | Planificarea avansată a calității produsului, pe faze, până la lansare | Rar relevant pentru supervizor |
| PPAP | Procesul de aprobare a pieselor de producție de către client | Doar stare / referință |
| FMEA / PFMEA | Analiza modurilor de defectare și a efectelor (proces). Severitate, apariție, detecție | O recurență poate indica actualizarea PFMEA (D7) |
| Control Plan | Caracteristicile controlate, metoda, frecvența și planul de reacție | Checklisturile de schimb pot trimite la el, fără a-l copia |
| SPC | Control statistic al procesului: hărți de control, capabilitate | Cere date măsurate. Nu se calculează din date numărate |
| MSA | Analiza sistemului de măsurare (de ex. R&R) | Contextul valabilității măsurătorilor |
| Trasabilitate | Legătura lot – mașină – schimb – operator – material | Id-uri, nu nume, în exemple |
| First Off | Verificarea primei piese după pornire sau schimbare | Checklist cu rezultat și oră |
| Caracteristici critice / speciale | Marcate de client sau intern (siguranță, funcție) | Câmp de marcare pe problemă |
| Quality gate | Punct de control obligatoriu înainte de etapa următoare | Stare blocantă |
| Red Box | Container marcat pentru piese suspecte sau neconforme | Locație în containment |
| QPS (Quality Problem Solving) | Format intern de rezolvare. Variază de la o companie la alta | De confirmat local |
